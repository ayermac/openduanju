# 已知限制与验证边界

[返回项目首页](../README.md)

当前为首版开发预览，没有生产容量、可用率或商业化能力承诺。下列状态应与具体接口及代码核对，不因示例链路成功而扩大结论。

## 来源和存储

- 正式元数据入口当前仅红果 Web 热播榜；分类入口、更多网站、新建来源/通道、通道并发总量治理尚未交付。
- SDK 的真实目录/分集读取曾通过探测，但真实播放解析返回空结果并映射为 `ErrAnonymousLimited`。原因未进一步证实，不认定一定是额度耗尽，也不承诺提供登录态即可解决。
- COS 适配器提供上传、版本绑定、确认与签名能力，但真实桶端到端验证未完成；默认验收使用 local 存储。
- 视频输出为单份 MP4/H.264/AAC，未实现 HLS/DASH 多码率处理；人工上传为单次 PUT，未实现分片和断点续传。
- 本仓库不附带来源设备档案、账号身份、授权材料或第三方视频。公开来源元数据可读取，不等于媒体可重新分发。

## 内容与体验

- 手工作品目前没有分类编辑字段；公开分类来自发布内容投影，人工样例可能没有分类标签。
- 逐条追加分集、删除/重排分集、分集标题维护及空标题宽松保存尚未实现。
- 本设备历史支持读取与续播，不支持单条删除/清空；不提供 C 端账号或跨设备同步。
- 已观察到 Enter 搜索同时触发表单与按键监听，可能重复发送两次列表请求，尚待修复。
- 部分移动控件有效触控尺寸仍需核对；浏览器验证以 Chromium 与移动视口为主，未完成 iOS/Android 真机验证。
- IAA 广告、归因、支付/解锁、个性化推荐、本站热度榜、运营位和数据看板不在当前实现中。

## 部署和排查

- 五服务 Compose 是本地开发/验收配置，绑定 loopback；不是可直接开放公网的生产模板。
- HTTPS、Secure Cookie、生产秘密管理、日志轮转、备份恢复、压测与高可用需要按部署环境补齐。
- Redis 仅部署预留，现有业务没有使用它提供缓存或全局限频。
- Trace 为基础上下文与日志关联；不等同于完整 Span 拓扑、OTLP 采集或监控告警平台。
- 真实 gRPC 客户端端到端覆盖不完整，不应由能力映射单测推断所有外部客户端调用都已验证。
- Kratos 初始化 Todo 样例仍在代码中，不属于短剧业务与权限承诺；生产暴露前需另行核对路由。
