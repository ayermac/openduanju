# 迁移目录

文件名格式：`NNNN_描述.sql`（至少4位数字，版本唯一且递增）。已应用文件不可改写；修改会被校验和拒绝。

规则：

- 每个文件可包含多条语句，由迁移器按引号/注释/分号切分；不要在存储过程或触发器内使用 `DELIMITER`。
- MySQL DDL 会隐式提交，因此迁移需可重复执行（`CREATE TABLE IF NOT EXISTS`、加列前检查），失败后人工修复再重跑。
- 不写 `DROP DATABASE`、跨库操作或依赖旧库数据；生产只执行评审过的增量迁移。
- 当前目录暂无业务迁移；SOURCE-001 将提交首个业务表迁移。迁移器/版本表由 `cmd/openduanju-migrate` 自动创建。
